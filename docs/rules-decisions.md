# 规则裁定记录

依据：官方规则书（2025）+ 2026-08 修订 + IELLO FAQ 2.0。规则书没写明的地方，按下表处理，代码中对应位置见 `src/shared/engine.ts`。

| # | 情形 | 裁定 |
|---|---|---|
| D1 | Blimp 的「第二个弯道」 | 15 号格：回合开始时位置 < 15 主移动 +3，否则 −1 |
| D2 | Blimp / Hare 卡面版本 | Blimp +3；Hare 跳过主移动时不拿铜分 |
| D3 | Copy Cat 自己独自领先 | 没有能力；领先并列时自动取优先级最高（当前玩家起顺时针）的那名 |
| D4 | Copy Cat 复制 Egg / Twin | 复制它们本场的生效能力；不复制任何赛前能力 |
| D5 | Egg 没选中的两张牌 | 弃掉，不回牌堆 |
| D6 | Suckerfish 能否跟随后退 | 可以；不能跟随瞬移和被 Huge Baby 挤动 |
| D7 | 场间先手：最落后并列 | 从本场先手起顺时针最近的玩家；有被淘汰者时取最先被淘汰者 |
| D8 | 2 人局场间先手 | 本场得分（金银铜合计）较低者，平局随机 |
| D9 | 已摔倒再被绊倒 | 无额外效果 |
| D10 | 循环判定 | 同一回合内，同一触发在完全相同的局面（位置/摔倒/完赛）下第二次出现时跳过；单回合结算步数 > 3000 视为无法结束，比赛终止，剩余名次无人得分 |
| D11 | Scoocher 的触发时机 | 能力事件进入队列，在当前后果结算完后统一挪动；Gunk/Coach 每次修正、Leaptoad 每跳一格、Magician 每次重掷、Dicemonger 每次被借用都各算一次 |
| D12 | Sisyphus 的分数筹码 | 每枚 1 分，最少扣到 0 |
| D13 | Mastermind 预测自己并猜中 | 第 1、第 2 名都归其玩家 |
| D14 | 掷骰交互 | 每个真人回合都需要点「掷骰」；AI 与托管立即执行 |
| D15 | 同时到达 | 一组同时移动（Party Animal、Cheerleader、Suckerfish 跟随、Flip Flop 交换、Huge Baby 挤动）的成员之间不触发停格能力；赛道格照常 |
| D16 | 选秀与首场先手的掷骰 | 直接随机 |
| D17 | 多个挪步者（模仿猫复制挪步者，或蛋蛋/双胞胎化身挪步者） | 挪步者因能力挪动这件事本身不再触发其他挪步者，否则两者会一格一格互相推到终点 |
| D18 | 吸盘鱼和挪步者反复互动 | 视为循环（用户裁定）：吸盘鱼跟随触发某挪步者，每回合每对只结算一次；同一回合内同意跟随某目标后自动跟随，不再重复询问 |
| D19 | 对局层面的死局（能力互相牵制，没人能冲线） | 单场超过 400 个回合视为循环，比赛结束，已产生的名次照常计分，剩余名次无人得分 |
